# LEGAL_NOTES

Правовые и методические заметки по проекту **Portrait Choice**

> ⚠️ Этот файл не является юридической консультацией.  
> Он нужен как рабочая памятка для аккуратной публикации учебного проекта.

---

# 1. Назначение проекта

Проект создаётся как:

- учебная демонстрация интерфейса;
- техническая реализация последовательности выбора портретов;
- локальный клиентский веб-инструмент без серверной интерпретации результатов.

Проект **не должен позиционироваться** как:

- клинический инструмент;
- диагностический сервис;
- медицинский или психологический сервис;
- средство постановки диагноза или профессионального заключения.

---

# 2. Методика и интерпретация

## В проекте НЕ реализуется:
- интерпретация результатов;
- клиническое заключение;
- психодиагностический вывод;
- автоматическая психологическая оценка.

## Важно:
Если в будущем в проект будет добавляться интерпретация, это может повлечь дополнительные:

- методические риски;
- правовые риски;
- этические ограничения;
- требования к квалификации пользователя.

---

# 3. Изображения / стимульный материал

## Нужно проверить источник каждого изображения:

Для каждого набора портретов желательно зафиксировать:

- откуда взято изображение;
- кто правообладатель;
- разрешено ли учебное использование;
- разрешено ли публичное размещение в интернете;
- есть ли ограничения на переработку / адаптацию / публикацию.

# 5. Если используются материалы существующей методики

Если изображения, структура серий, порядок предъявления или иные элементы заимствуются из:

- опубликованной методики,
- сайта,
- книги,
- адаптированной батареи тестов,
- существующего интернет-сервиса,

нужно отдельно проверить:

- охраняется ли это авторским правом;
- разрешено ли воспроизведение;
- разрешено ли публичное распространение;
- разрешено ли создание производной веб-реализации.

# 7. Персональные данные

Текущая версия проекта:

- не использует базу данных;
- не отправляет ответы на сервер;
- хранит данные только локально в браузере пользователя.

Это снижает риски, но важно помнить:

## Даже при локальном хранении желательно:
- не просить лишние персональные данные;
- не собирать ФИО, email, телефон без необходимости;
- не добавлять формы идентификации без понимания правовых последствий.

---

Если в будущем вы добавите:

- авторизацию;
- регистрацию;

- хранение результатов в БД;

- политику конфиденциальности;
- согласие пользователя;
- срок хранения данных;
- доступ к данным;
- экспорт / удаление данных;
- применимые требования GDPR / локального законодательства.

Если проект публикуется как:

- учебная работа,
- демонстрация интерфейса,
- технический pet-project,
- исследовательский прототип,

то безопаснее формулировать описание примерно так:

## Рекомендуемая формулировка:
> Учебный веб-проект, демонстрирующий интерфейс последовательного портретного выбора без интерпретации результатов.
